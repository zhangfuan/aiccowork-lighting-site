# AICCO WORK Lighting Independent Site

This is a static B2B automotive lighting website package based on AICCO WORK / Zhengzhou Runcai Lighting product information.

## What changed in this version

- Homepage structure rebuilt with a stronger automotive e-commerce layout.
- Added top promotion bar, sticky navigation, mega-menu style product navigation, and shop-by-application sourcing finder.
- Reorganized products into buyer-friendly collections and featured product cards.
- Added B2B support sections: applications, OEM/ODM, quality assurance, resources, inquiry form and footer navigation.
- Kept existing contact details: admin@smartfz.com, WhatsApp / Wechat +86 13523061119, Alibaba store link.

## Files

- `index.html` — Homepage
- `thank-you.html` — Form submission success page
- `assets/css/style.css` — Main styles
- `assets/js/main.js` — Mobile menu, product filter, finder, back-to-top behavior
- `assets/images/` — Product and support images
- `robots.txt`, `sitemap.xml` — Basic SEO files
- `netlify.toml`, `vercel.json` — Deployment configs

## Deploy

### Netlify
Upload the full folder to Netlify. The inquiry form uses Netlify Forms and can work without backend code.

### Vercel / GitHub Pages / cPanel / Server
Upload all files to your site root. For inquiry collection, connect the form to your preferred form service, email API or backend.

## Replace before launch

1. Replace placeholder domain in meta tags and `sitemap.xml` with your real domain.
2. Replace product images with your newest product main images.
3. Update product parameters, MOQ, lead time and certifications when you have final data.
4. Test WhatsApp, email and Alibaba links.
